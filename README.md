This project is developed using Java.

Project Description
The Student Grade Management System is a console-based Java application that allows users to enter student details and marks in three subjects. The program calculates total marks, average marks, percentage, grade, and displays the final student report card.

Features
Enter student name and roll number
Input marks for 3 subjects
Calculate total marks
Calculate average and percentage
Generate grades (A/B/C/D/F)
Display pass or fail result
Display remarks and performance message
